PWM 控制 (QX-DO24)

Hz（鎖定） %（1.00 ms）
—
  • 占空比 5.0~10.0%（可到小數第一位）：5% = 停止、10% = 全速，超出範圍後端一律拒絕、不送出
  • 順序是頻率 → 占空比 → 控制，控制最後才開，馬達不會在開輸出瞬間衝出去
  • 暫存寫入：斷電就還原（模組回到 1000Hz / 50% / 關閉），可無限次修改
  • ⚠ 保存參數：寫入 flash 存成開機預設。壽命只有 1~2 千次、每次上電只能存一次；若存檔當下控制是「持續輸出」，模組以後一通電就會立刻驅動馬達——按下前請先確認控制值
  • 模組每次上電頻率會跳回 1000Hz，占空比對應會失效 → 先按「讀回現況」確認，需要時重按一次暫存寫入
