# axis_profile — 機構標定。跟著**機器**走，不跟著設備型號走。
#
# 🔴 為什麼與 device_profile 分開：換一顆同型馬達不該把機構標定重置。
#    `ARM_RAIL_LEAD_CM_PER_REV` 是**皮帶軸**的性質，不是驅動器的 ——
#    程式曾經假設 1.0，於是每個 cm 指令實際走 7.7 倍，`ARM_SWEEP_CM=17`
#    實際下 131cm 而滑台只有 50cm，**每次掃動都一路撞到底，四個月沒人被告知**。
#
# 🔴 這個檔**不存在也完全正常** —— 沒有它就走編譯進去的常數，行為逐位元相同。
#    它存在的意義是：換機器 / 重新標定時，改這裡而不是改程式碼。
#
# ⚠️ 每個值都要有 .provenance。看不到來源的覆寫本身就是警訊 ——
#    載入器會在覆寫生效時把 provenance 一起印出來，沒有的話印「⚠ 無 provenance」。
