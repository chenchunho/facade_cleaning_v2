# SE3 變頻器參數(吊機左右繩,Shihlin SE3-210)

`se3_left_<日期>.txt` / `se3_right_<日期>.txt`:兩台 SE3 的**全參數傾印**(P.0–P.999 可讀的 880 個),
用 `scripts/vfd_se3_clone.py dump` 讀出。`se3_diff_<日期>.txt` 是左右差異。

**已知的專案設定值**(其餘見手冊 `變頻器SE3系列操作手冊 V1.03.pdf`,不在 repo):

| P | 值 | 意義 |
|---|---|---|
| P.79 | 3 | 操作模式 = 通訊(CU) |
| P.36 | 1 | 站號(兩台各自在自己的網關上,都用 1) |
| P.32/33/48/49/50/154 | 5/0/0/1/0/3 | 115200 / Modbus / 8 bit / 2 stop / 無同位 / 格式 1,8,N,2 |
| P.7 / P.8 | 10 / 50 | 加速 1.0 s / 減速 5.0 s(**左右必須相同**,見 memory) |
| P.10 / 11 / 12 | 300 / 5 / 40 | 直流制動 3.00 Hz / 0.5 s / 40 %(**左右必須相同**) |
| P.1 / P.2 | 5000 / 6(左) 0(右) | 上限 50.00 Hz / 下限 0.06 vs 0 Hz —— 09-17 **唯一有意義的左右差異** |

`se3_diff` 裡其他 7 個(P.292/296/298/755/757/769/771)是**累計計數/監視值**(兩次讀取之間會變,例如 P.296 1317→1319),不是設定,複製時被拒或不同都正常。

**複製到另一台機器**:
```
python3 scripts/vfd_se3_clone.py write 192.168.1.30 config/vfd/se3_left_2026-09-17.txt          # 先 dry-run 看差異
python3 scripts/vfd_se3_clone.py write 192.168.1.30 config/vfd/se3_left_2026-09-17.txt --apply  # 寫入 + 逐項回讀
```
前提:目標機停機、接在同鮑率(115200 8N2)網關、slave 1;腳本會跳過站號與命令暫存器,唯讀暫存器被拒只記錄。寫完斷電重開再 `dump` 一次比對。
