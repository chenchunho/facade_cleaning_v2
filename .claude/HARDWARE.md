## 2. 網路拓樸

```
 外部(頂樓/地面)                                         機身 / 頂樓
   ──2-wire tether(HomePlug AV)──► Fathom-X Tether Board ──Ethernet──► 8-Port PoE Switch
                                                                            │
                        ┌──────────────────┬────────────────────────────────┼──────────────┐
                    本體 Pi5            吊機 Pi                      6× USR-TCP232-304    X518(原生 TCP)
                    192.168.1.100       192.168.1.10                 (RS485↔TCP 透明傳輸)  192.168.1.33:502
                    WiFi 192.168.5.26   WiFi 192.168.5.25            .20 .21 .22(本體)
                                                                     .30 .31 .34(吊機) + .32 ZS-DIO
```

- 🔴 **HomePlug AV(2–30 MHz)與 VFD 噪訊同頻帶**:2026-09-08 受控實驗 VFD 一運轉該鏈路掉 **90%** 封包
  (同一秒 WiFi 90/90 全通)。⇒ **目前上機測試暫全走 WiFi**(`SOFTWARE.md` §1.3),有線是既定終點但物理層要先解(隔離/濾波,見 `plans/wired_switch_and_loop_test_plan.md`)。
- 網關全為 USR-TCP232-304,**透明傳輸**(非 Modbus 閘道):回覆會被切成多個 TCP 段、每台最多 4 條 TCP 連線、半雙工序列化 —— 三個結構性問題見 `reference/comms_interface_for_pcb.md` §4。
- **本體與吊機各自獨立電控箱**(5V 電源分開,見 §5)。**RS485 主匯流排網關 6 台**(USR-TCP232-304):本體 3(.20/.21/.22)、吊機 3(.30/.31/.34);另有水閥網關 `.32`(ZS-DIO/USR_W,2026-09-10 加)與 X518 張力(原生 TCP `.33`)。
- 主機端點可用 `FCV_EP_<NAME>_HOST/PORT` 執行期覆寫(`common/endpoints.h`)。

## 5. 電源架構 🔴(跟 24V blip 直接相關)

三組電源皆由 200 m 電纜(中央捲盤)送 AC 上機身後自行轉換。**下表依 per user 2026-09-12 口述 + 設計彙整 §3.6**;標 🔴 的仍待現場確認。

| 電源 | 規格 | 負載 | 備註 |
|---|---|---|---|
| **24V — 全系統只有一顆** | LRS-150-24,24V / **150 W(6.25 A)** | **所有 24V 負載共用**:**手臂 M1(DM10010L)+ M2(DM4340)**(per user 2026-09-12 確認)、ZDT 推桿 ×4、上滑台抱閘(常時通電)、滾筒馬達 ×2、真空幫浦 A/B、PQW 繼電器、真空閥/正壓閥、控制 | 🔴 **這就是 24V bus,也是 blip 根因**。M1 堵轉峰值 + 幫浦 + 推桿同時 → 150 W 不足 → 24V 垂降 → 繼電器/幫浦掉、ZDT 計數器亂 |
| **5V ×2(分開)** | 各電控箱一顆 | **本體電控箱**:USR 網關 .20/.21/.22;**吊機電控箱**:USR 網關 .30/.31/.34 + 水閥網關 `.32` | per user 2026-09-12:**吊機與本體各自電控箱、5V 分開**,不是同一顆;獨立於 24V |
| **Pi5 ×2** | 各自獨立供電 | 本體 Pi5、吊機 Pi | 獨立;blip 時 Pi 不重開(2026-09-11 是使用者手動斷電) |
| **48V(滑台)** | LRS-150-48,48V / **150 W** | DM2J 上滑台**獨立一顆** | 只供滑台;M2 雖為 48V 型,實裝**接 24V**(per user) |
| **57.6V(螺旋槳)** | NPP-1700-48 ×2,**並聯輸出** | ESC ×2(兩具螺旋槳) | per user 2026-09-12:兩顆並聯供螺旋槳;獨立,不影響 24V |

**24V blip 事件鏈(2026-09-11 三次)**:手臂 15 Nm 壓硬物(橫桿)堵轉 → 過流 → **唯一那顆 150 W 24V 垂降** → PQW 繼電器全掉
(幫浦/閥 off)+ ZDT 驅動器位置計數器亂 → 需 `zdt_home feet` 復位。降力到 8 Nm 後未再發生(雙工具 + 滑台掃實測)。
**根因(2026-09-12 per user 確認)**:單顆 150 W 24V 供全部 24V 負載**含手臂 M1/M2**,無餘裕吸收 M1 堵轉峰值。
**對策方向**:① 量 24V 實際總負載與堵轉峰值 ② **把手臂 M1/M2(及/或幫浦)分離到獨立電源**,或加大 24V 供電
③ 加斷路/限流保護 ④ 軟體側已降力 8 Nm 緩解(治標)。

**待現場確認**:24V 實際總負載與峰值;斷路器/保險絲規格;MH300 中繩絞盤供電。

## 6. 安全相關硬體機制

| 機制 | 行為 | 意義 |
|---|---|---|
| 真空閥 三口二位 | **斷電 = 破真空** | fail-safe:失電吸盤自動放開(所以斷電後機器靠鋼索,不靠吸盤) |
| 上滑台馬達抱閘 | **失電抱閘**(24V 常時通電才鬆) | 斷電滑台不滑;但抱閘電源在 24V bus 上 |
| 吊機捲揚 | 機械煞車 | 2026-09-11 雙 Pi 斷電實測**機器沒掉**,SD76 絕對位置保留 |
| PWM 模組(QX-DO24) | **斷線維持輸出**(✅ per user 2026-09-12 確認) | ⚠️ 網路斷了螺旋槳**會持續推**——這是已確認的行為,保護要在系統層(watchdog/急停)做 |
| X518 | 只允許 1 條 TCP 連線 | 外部工具要連必須先停吊機程式 |
| 手臂 `:9527` | 綁 `0.0.0.0`、**無驗證** | 同網段任何主機可直接下 DEPLOY;GUI 端已加武裝互鎖,網路層仍裸 |
| 吊機張力保護 | up_stop_total / tension_max / diff_max / retract_tension_stop | 由 Crane 程式執行,X518 為輸入 |
