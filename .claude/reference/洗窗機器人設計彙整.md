# 吊掛式外牆洗窗機器人 — 系統設計彙整

更新日期：2026-08-27

---

## 1. 系統概述

兩台頂樓吊機以 ø6mm 鋼索垂吊機器人本體，中央捲盤同步收放水管與網路電纜（200m）。本體以四個突出 50mm 的輪子貼在玻璃上滾動升降，由兩具 22 吋螺旋槳提供貼牆推力；定點清洗時四支電動缸推出 ø200mm 吸盤吸附鎖定，本體上方的橫向滑台帶動滾筒與刮刀左右往復清洗。

清洗由上往下逐段進行，到達 1 樓後人工橫移吊機一列，再提升回頂重複，直到整面立面完成。

**控制架構為雙主控**：頂樓 Pi 管吊機與計米器，機上 Pi 5 管本體所有設備，兩端透過電力載波以乙太網路互通。

## 2. 現場作業流程

### 2.1 六個作業步驟

| 步驟 | 內容 |
|---|---|
| 1 | 頂樓部署吊機並錨定，設置地面警戒區 |
| 2 | 鋼索、水管、電纜同步下放至 1 樓 |
| 3 | 地面安裝本體、接續管線，開機自檢與連線測試 |
| 4 | 收線提升至最高一片玻璃對位 |
| 5 | 由上往下逐段清洗至 1 樓 |
| 6 | 人工橫移吊機一列（斷電上鎖），空載提升回頂，重複步驟 5 |

全部完成後下放拆機、收工檢查與記錄。

### 2.2 單段清洗序列

1. 本段定位，四支電動缸推出吸盤吸附
2. 去程：噴水＋滾筒刷洗（左→右，行程 1m）
3. 回程：刮刀收水（右→左，停止供水）
4. 清潔度確認，未通過則重刷（上限 2 次）
5. 手臂歸位、刮刀抬起、滾筒停轉、水路關閉
6. 破真空，四缸收回至輪子接觸
7. 下放一個固定段高，重複

### 2.3 四軸吸盤貼附序列

1. 四缸快速伸出至接近距離
2. 切換慢速微動，逐缸偵測接觸（碰到即停）
3. 未接觸者續伸，超過 200mm 行程即報錯
4. 抽真空，四路獨立監測
5. 單顆未達標 → 該軸電動缸微退 2mm 重貼（不破真空），上限 3 次
6. 仍不足 → 四閥一起破真空、四缸全收，整段重新貼附
7. 由四缸行程差計算玻璃面傾角，供手臂貼壓補償
8. 鎖定位置（螺桿自鎖），開始清洗

### 2.4 破真空時序

真空三口二位閥先切至大氣位 → 正壓補入加速脫離 → 電動缸收回。

### 2.5 安全監控（與主流程並行）

監控項目：通訊逾時、鋼索張力異常、姿態超限、環境異常（強風、漏水）。

任一觸發 → 進入安全模式 → 維持吸盤吸附、停手臂、關水、槳降至保壓 → 吊機停止並鎖定 → 通報頂樓與地面 → 人工介入回收。

## 4. 節拍估算

以段高 450mm（滾筒 510mm 扣 60mm 重疊）、立面高度 200m 計：

| 項目 | 數值 |
|---|---|
| 段數 | 約 445 段 |
| 貼附與抽真空 | 約 20 秒 |
| 清洗兩趟行程 | 約 13 秒 |
| 破真空與收回 | 約 5 秒 |
| 下放定位 | 約 3 秒 |
| **單段合計** | **約 41 秒** |
| **單列合計** | **約 5 小時** |

瓶頸為抽真空（佔單段一半）。450mm 段高正好是 3.6m 標準樓高的八分之一，可與每層歸零校正對齊。

### 暫緩項目

以下已識別但目前不處理，實機測試時可能浮現：

- 空壓機啟動與電動缸同動的電流重疊（症狀：電動缸偶發失步或抱閘異響）
- 空壓機振動對陀螺儀姿態判斷的干擾
- Pi 未讀取儲氣筒壓力，假設氣壓恆定可用

## 7. 設計要點備忘

**貼附順序**：先讓螺旋槳把機體壓穩，再啟動吸盤真空，最後降低槳推力但不歸零；釋放時反序。

**四點過約束**：三點即可決定平面，第四點必然先碰或受力偏大。前三缸接觸後停住並記錄位置，第四缸單獨推進到接觸為止。四缸位置差即為機體相對玻璃面的傾角，比陀螺儀對重力的角度更有用。

**推力與貼壓分離**：滾筒刮刀在本體上方、螺旋槳在中段，推力作用線低於刮刀位置會產生向外翻的力矩。清洗時應由上方兩個吸盤承擔貼壓剛性。

**清洗方向**：由上往下，污水順流至未清洗區。橫移方向宜順當天風向的下風處推進。

**變頻器與載波干擾**：變頻器載波頻率 2～8kHz 的雜訊會沿電源線干擾同一條電纜上的網路訊號。變頻器輸入端裝 EMI 濾波器，輸出至馬達用屏蔽線單點接地，載波電纜與動力線分槽走。

**RS485 佈線**：屏蔽雙絞，兩端各 120Ω 終端電阻。機上與頂樓為獨立網段。

**洩漏率診斷**：貼附完成後關閥、停幫浦，量測壓力變化率。幾乎不變為密封良好；緩慢上升為微漏可補抽；快速上升則重貼或跳段。

**壓力表零點校正**：每次破真空後吸盤處於大氣壓時讀值應為 0，可作為自動零點校正，並藉此發現故障的表。

**耗材**：510mm 滾筒與 365mm 刮膠為市面標準尺寸，現場可換。
