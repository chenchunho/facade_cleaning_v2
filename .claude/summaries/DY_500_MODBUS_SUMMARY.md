## Overview

**稱重變送器**：吃應變片（load cell）的 mV 訊號，同時輸出 **RS485 Modbus-RTU** 與**類比 4-20 mA / 0-10 V**，
兩路可同時精準輸出。供電 12–26 V DC、功耗 < 3 W。採集精度 12–16 位（隨採樣速度變動）。

## Modbus-RTU

**出廠：19200 / N81 / 機碼 1。** 通訊速率可設 2400–115200。
🔴 **修改波特率要重啟儀表才生效。**

### 只支援兩個功能碼
- **`03`** 讀資料、**`10`（16）** 寫資料
- 🔴 **v1.4 起「去除了 05 命令的支援」** —— 舊文件或舊程式若用 FC 05 會失敗
- 資料包最大 100 bytes、資料個數 < 20（每個資料 4 bytes）
- **每個參數佔 2 個位址**（32 位）

### 🔴 手冊給了兩套位址，而範例用的是短的那套

| | 位址型式 | 例 |
|---|---|---|
| 「40000 起算」 | `0x9C40` = 40000 | 測量值 |
| 短式 | `0x0606` / `0x062A` … | 同一個參數的另一個位址 |

**LONG 型位址 +100(十進位) 就是 FLOAT 型**：`0x9C40`(LONG) ↔ `0x9CA4`(FLOAT)。

⚠️ **手冊自己的範例全部用短式**（清零寫 `0x062A`、標定重量寫 `0x0628`），
但參數表主要以 `0x9Cxx` 排列。**接線調試時先用範例那套試通，再擴充。**

### 唯讀量測暫存器

| LONG | FLOAT | 內容 |
|---|---|---|
| `0x9C40` | `0x9CA4` | **測量值**（當前重量） |
| `0x9C42` | `0x9CA6` | AD 碼值 |
| `0x9C44` | `0x9CA8` | DA 碼值 |
| `0x9C46` | `0x9CAA` | **系統狀態**：`1` = 穩定、`0` = 不穩定、`3` = 空載 |

📌 **`系統狀態` 值得用**：讀到重量之前先確認 `=1`，可以避開晃動中的假值。

### 多功能暫存器（範例位址 `0x062A`）

寫入下列值觸發動作：

| 值 | 動作 |
|---|---|
| `1` | 清零 |
| `10` | 確認**數字校準**（用靈敏度＋量程算） |
| `11` | 確認**砝碼校準**（實物） |
| `12` / `14` | 保存 AD 零點／滿度 |
| `17` / `18` | 保存變送零點／滿度 |
| `30` | **部分**恢復出廠（硬體校準參數**不**恢復） |
| `31` | **完全**恢復出廠 |
| `40` | **保存參數修改** |

**砝碼校準流程**（手冊 §6）：
1. 空載 → 寫 `1`（清零）
2. 加載並穩定 → 把**標定重量**寫進 `0x0628`（例：`00 00 27 10` = 10000）
3. 寫 `11` 確認
4. 寫 `40` 保存

**數字校準流程**：寫靈敏度（`0x9C7C`，**2.0000 mV/V 要寫 20000**）→ 寫量程（`0x9C82`）→ 寫 `10` 確認 → 寫 `40` 保存。

## 🔴 上電清零預設是**開啟**的

`清零設定`（`0x9C5E` / 範例 `0x0426`）預設 **1101**，四位各自獨立：

| 位 | 意義 | 預設 |
|---|---|---|
| 千位 | 參數修改自動保存 | **1 = 有效** |
| 百位 | 0=清零不保存／1=手動清零保存／2=自動清零保存 | **1** |
| 十位 | 自動清零功能 | 0 = 無效 |
| 個位 | 上電清零 | **1 = 有效** |

⇒ **上電時的負載會被當成零點吃掉**，範圍受 `上電清零範圍`（`0x9C54`，預設 100）限制。
📌 這與 X518 是同一個陷阱（見 `DSZL_107_X518_MODBUS_SUMMARY.md`）——
**這類稱重模組預設都會上電清零**，接鋼索這種「靜止時本來就有張力」的場合要特別確認。

手冊給的三組組合值：
```
上電清零 + 自動清零 都有效 : 寫 0x000B (11)
上電清零無效、自動清零有效 : 寫 0x000A (10)
上電清零有效、自動清零無效 : 寫 0x0001 (1)
```

**自動清零要六個條件同時成立**才觸發（手冊注釋八）：功能已開、當前值 > 觸發門限、卸載後 < 門限、
上電清零範圍 > 當前值、卸載後停留 > 延時、然後才清零。⇒ 誤觸發機率低，但不是不可能。

> 「若當前為主動上傳模式，**需恢復出廠設置才能切換到 modbusRTU 模式**！」

## 類比輸出校準公式（本專案未使用，但列出免得重查）

```
0-10V ： 輸出電壓 = 已知重量 / 傳感器總量程 × 10V + 零點
0-5V  ： 輸出電壓 = 已知重量 / 傳感器總量程 × 5V  + 零點
0-5-10V（拉壓雙向）： 以 5V 為零點，淨輸出 5V
```
⚠️ **變送器無負電壓輸出**，感測器要做拉壓（正反扭矩）時必須用 0-5-10V 那種接法。

## TEDS 自動校準

`自動校準`（`0x9C84`，預設 0）設為 1 時，搭配**本公司帶 TEDS 功能的感測器**可上電自動校準。
傳感器編碼在 `0x07D0`。⚠️ 只對該廠 TEDS 感測器有效。
